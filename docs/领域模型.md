# 领域模型

```text
来源 Source
  └─包含→ 内容卡 ContentCard
                ├─抽取→ 研究命题 Thesis
                │          ├─引用→ 证据 Evidence
                │          └─进入→ 盲预测 Forecast
                │                         └─到期→ 复盘 Retro
                ├─触发→ 及时线索 Alert
                │          └─进入→ 核验队列 VerificationQueue
                └─归入→ 主题 Theme
```

## 最小字段

| 对象 | 必填字段 |
|---|---|
| Source | source_id、平台、URL、发布时间、抓取时间、内容形式 |
| ContentCard | source_id、分类、摘要、事实、观点、推断、纳入理由 |
| Thesis | 命题、变量/标的、方向、时间窗、条件、失效标准 |
| Evidence | 来源、发布日期、等级、支持/反驳、口径、局限 |
| Forecast | 冻结时间、预测文本、基准、到期日、状态 |
| Retro | 实际结果、误差分类、证据变化、方法更新 |
| Alert | 发现时间、时效窗口、影响标的、等级、状态、核验截止时间 |
| VerificationQueue | 外部验证、结论、风险提示、是否升级为 A 轨命题 |

## 状态流转

`发现 → 已登记 → 已拆解 → 待核验 → 可预测 → 已冻结 → 待复盘 → 已复盘`

若内容属于非投资表达，则流转为 `已登记 → 非投资存档`，不计入预测表现。

两条状态流：A 轨为 `内容卡 → 命题 → 盲预测 → 到期 → 复盘`；B 轨为 `发现 → 快速提醒 → 外部核验 → 暂存/升级为命题/关闭`。
