# 及时投资线索提醒规则

## 提醒的最低条件

同时满足以下条件才进入 B 轨：

1. 内容与宏观变量、市场、行业、公司或具体资产相关；
2. 存在明确时间敏感性，延迟处理可能损失研究价值；
3. 能识别潜在影响标的或变量；
4. 可以用公开外部来源核验，或明确标记为“仅待核验线索”。

## 优先级

- **P0：立即核验**：重大事件、公告、监管变化、业绩/资本开支/订单等，可能在 1–3 个交易日内影响价格。
- **P1：当日处理**：行业政策、宏观数据、重要会议、产业链变化或公司经营趋势，影响窗口为数日到数周。
- **P2：进入研究池**：潜在线索价值存在，但时效性、标的或证据尚不清晰，无需打断式提醒。

## 提醒卡格式

```text
[P0/P1/P2] {{主题}}｜{{发现时间}}
作者表达：{{短摘录或准确概括}}
潜在影响：{{标的/行业/宏观变量}}
时效窗口：{{例如 1–3 个交易日 / 1–3 个月}}
当前状态：未核验 / 部分核验 / 已核验 / 已关闭
下一步：{{查公告、查数据、查财报、查行情或暂不行动}}
风险：作者表达不等于事实；可能存在断章取义、时点滞后或市场已定价。
```

## 不得升级为强提醒的情况

- 只有情绪、口号或泛泛看多看空，没有变量和时间窗；
- 仅为转发、评论区内容或无法确认来源的二手剪辑；
- 线索无法指向具体可核验事实；
- 已经发生很久且没有新的边际信息。
