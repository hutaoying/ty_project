# ADR-001：研究对象与边界

## 状态

暂定，待用户确认。

## 决策

工作台将青枫浦上Q的公开内容视为“待核验的研究输入”，而不是权威事实或自动化交易信号，并采用 A/B 双轨：A 轨分析方法论与预测能力，B 轨处理及时投资线索提醒。

系统分别保存：

- 原文或原始页面信息；
- 作者明确说出的判断；
- 从判断中抽取的可检验命题；
- 外部数据对命题的支持、反驳或尚未验证状态；
- 复盘结果与方法更新。
- B 轨额外保存发现时间、时效窗口、潜在影响标的、提醒等级、核验截止时间和处理状态。

## 原因

当前公开检索显示，该账号在 B 站发布 A 股、宏观和公司议题，也会发布科技、社会与日常内容。若不做范围分层，样本会把表达风格、热点评论和投资判断混为一谈，导致准确率与能力评估失真。

## 不在第一阶段做的事

- 不根据单条视频直接生成买卖指令。
- 不将粉丝数、播放量或语气自信度当作投资能力证据。
- 不采集登录后内容、私信、付费群或疑似泄露信息。
- 不复制大段视频字幕或文章全文；只保留研究所需的短摘录与结构化摘要。

## 影响

两轨分开计分：B 轨评价提醒及时性、核验完成率和线索有效性，不直接并入作者预测胜率；A 轨评价论证结构、证据质量、命题清晰度与兑现结果。
