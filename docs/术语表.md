# 术语表

| 术语 | 定义 | 记录要求 |
|---|---|---|
| 来源 Source | 可定位的公开页面、视频、动态或直播回放 | URL、平台、发布时间、抓取时间 |
| 内容卡 Content Card | 对一条内容的结构化拆解 | 事实、观点、推断、建议分开 |
| 研究命题 Thesis | 能被未来数据支持或反驳的判断 | 标的/变量、方向、时间窗、条件 |
| 证据 Evidence | 支持或反驳命题的材料 | 来源、发布日期、数据口径、局限 |
| 失效标准 Falsifier | 什么结果出现时应承认判断失效 | 必须可观测、尽量量化 |
| 盲预测 Blind Forecast | 结果发生前冻结的预测记录 | 创建后不可回填式改写 |
| 复盘 Retro | 到期后对预测进行结果和原因分析 | 区分方向错、时点错、条件错、证据错 |
| 主题 Theme | 一组跨内容反复出现的宏观/行业/公司问题 | 维护首次出现、最近更新、相关命题 |
| 非投资表达 Noise | 与投资研究无直接关系的内容 | 保留索引，不纳入预测评分 |
| 证据等级 | A 一手原始数据；B 权威二手资料；C 作者原话；D 转述/评论 | 命题至少标注一项等级 |
