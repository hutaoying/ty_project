# 青枫浦上Q投研工作台

这是一个“公开内容研究、线索提醒与观点校准”工作台：收集青枫浦上Q在 B 站及其他公开渠道的内容，抽取可检验的事实、判断、假设与行动建议，再与独立数据源核验，最后追踪判断是否兑现。

## 双轨目标

### A 轨：方法论与预测能力分析

这是主线。重点观察作者如何选题、建立因果链、使用证据、处理不确定性、给出时间窗，以及判断在事后是否兑现。

### B 轨：及时投资线索提醒

这是副线。遇到可能影响资产价格、且具有时效性的内容，先快速提醒，再进入核验队列。提醒不等于认可，更不等于买卖建议；必须标明“作者原话 / 外部验证 / 尚未验证”。

## 先定边界

- 研究对象是公开表达，不等同于投资顾问意见，也不构成买卖建议。
- 内容作者的观点与事实证据分开记录；二手转述、评论区和剪辑内容默认降级处理。
- 只有带时间、标的/变量、方向、条件和失效标准的表达，才进入“可复盘预测”。
- 工作台的目标不是复制个人交易，而是识别其研究框架、信息优势、常见误差与可验证能力。

## 目录

```text

```

## 当前工作流

1. 登记来源：URL、平台、发布时间、标题、内容类型、抓取时间。
2. 做内容卡：事实 / 观点 / 推断 / 情绪表达 / 行动建议分栏。
3. 建证据链：为关键事实补一手或高质量数据源，并注明发布日期。
4. 形成研究命题：变量、方向、时间窗、条件、失效标准。
5. 若内容及时且可能影响决策，先按规则生成 B 轨提醒。
6. 对 A 轨命题发布前盲预测：冻结判断，不在结果出来后改写原意。
7. T+3d / T+30d / 财报期复盘：记录结果、误差来源与是否更新方法。

## 第一批建议范围

先只研究近 12 个月中明确涉及宏观、A 股、行业或公司的内容，目标 20 条内容卡、10 条可检验命题；科技产品、社会新闻和纯转发暂存但不计入预测准确率。

## 待用户确认的关键问题

1. 主要市场是 A 股，还是还包括港股、美股、基金、债券与宏观资产？
2. 及时线索需要工作台内收件箱，还是还需要桌面/邮件/即时通讯通知？
3. 你的复盘周期偏短线（3–20 个交易日）、波段（1–6 个月）还是长期（1 年以上）？
4. 是否允许工作台使用付费数据源或券商研报？默认只使用公开、可追溯来源。
5. 最终交付是本地 Markdown 知识库，还是还需要表格/网页仪表盘？
